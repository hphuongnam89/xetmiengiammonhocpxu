- `DEMO-only-university-transcript.pdf`: sinh vien gia, trinh do cu nhan, hoc phan ACC1011.

Tai khoan demo chi duoc tao trong SQLite local cua may phat trien hien tai, khong duoc luu trong Git va khong duoc tao tren production. Vao `/app/submissions/new/`, chon nganh dich co trong danh sach, chon `demo_teacher`, tai PDF len; sau do vao ho so va bam **Phan tich ho so va tao de xuat so bo**.
