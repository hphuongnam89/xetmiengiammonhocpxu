# Metrics

- Hồ sơ: đếm theo workflow status.
- Người dùng: tổng tài khoản và phân bố theo role.
- AI usage: request count, input/output token và recorded cost theo provider/model/operation.
- Không hiển thị API key, prompt hoặc dữ liệu hồ sơ trong trang metrics.
- Cost có thể thiếu nếu provider integration chưa ghi event hoặc bảng giá chưa được cấu hình.
