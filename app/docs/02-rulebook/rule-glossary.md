# Rulebook Glossary

- **Recognition:** Comparing previously accumulated learning with the current curriculum.
- **Full recognition:** The evidence covers the current course content and volume sufficiently for the course to be recognized as a whole.
- **Partial recognition:** The evidence covers only part of a current course; missing content remains to be completed and assessed.
- **Conversion:** Converting prior learning units, grades, or certificates into the current curriculum's course result.
- **DVTHT:** The prior-program learning unit used in the source rule tables. Its conversion must use the published source table, not an inferred formula.
- **Current curriculum:** The target program and curriculum version for the student.
- **Source evidence:** A document, page, sheet, cell range, or teacher-approved record supporting a result.
- **NEEDS_HUMAN_CONFIRMATION:** A status for a rule or mapping that has not been manually verified from the scanned source.
- **Teacher decision:** The final per-course result entered or confirmed by an authorized teacher. It is distinct from an AI recommendation.

The rulebook is source-cited and versioned. Historical Excel outcomes are evidence for calibration only; they are not rules by themselves.
