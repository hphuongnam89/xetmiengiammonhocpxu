# Academic Owner Review Checklist

For every detailed mapping, confirm:

- [ ] Exact source document and page.
- [ ] Condition and eligible population.
- [ ] Source qualification or course.
- [ ] Target course or recognition outcome.
- [ ] Resulting score and credits.
- [ ] Effective date and curriculum version.
- [ ] Exceptions and missing-evidence behavior.
- [ ] Boundary and negative test cases.
- [ ] Whether the rule is active, historical, or informational only.

The reviewer must initial or sign the approved rule version. A rule without owner approval remains `needs_human_confirmation`.
