# Phase 2 Risks

- OCR or visual transcription errors can change a threshold or course mapping.
- Some table wording uses alternative units and requires academic confirmation before coding.
- Detailed political theory, law, national defense, physical education, English certificate, and IT certificate mappings need manual data entry and review.
- The 50% recognition cap must be tested against the exact curriculum denominator and exclusions.
- A rule can be legally valid but still require teacher review because the student's evidence is incomplete.
