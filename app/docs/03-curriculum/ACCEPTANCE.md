# Phase 3 Acceptance Criteria

- All six workbooks have a sheet-classification record.
- The normalized schema supports program, curriculum version, section, course, prerequisite, and source evidence.
- At least one representative curriculum sheet per workbook has its header variation documented.
- Raw values and source locations remain traceable.
- Student sheets, blank sheets, formulas, sample sheets, and old/new versions are not silently imported.
- No curriculum or student source file is modified.
- No course equivalence is created in this phase.
