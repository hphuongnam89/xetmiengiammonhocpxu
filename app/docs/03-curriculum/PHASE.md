# Phase 3: Curriculum Normalization

## Objective

Define a common representation for curriculum data across the six XLSX workbooks while preserving raw values and exact workbook/sheet/cell evidence.

## Scope

This phase covers curriculum definitions and structural classification only. It does not import student decisions or create course-equivalence mappings.

## Deliverables

- Normalized data dictionary.
- Import specification.
- Quality rules.
- Source-sheet classification.
- Schema and handoff records.
