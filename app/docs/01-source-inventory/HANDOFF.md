# Phase 1 Handoff

## Inputs for Phase 2

- The registered PDF rule and governance sources.
- The registered curriculum workbooks and historical review workbook.
- File metadata, workbook roles, and known quality limitations.

## Phase 2 must decide

- Which PDF clauses become active rule records.
- Which curriculum version applies to each program and cohort.
- Which historical spreadsheet decisions are sufficiently evidenced for calibration.
- How OCR corrections and ambiguous course mappings receive human approval.

Phase 2 must preserve the source register and must not overwrite the original files.
