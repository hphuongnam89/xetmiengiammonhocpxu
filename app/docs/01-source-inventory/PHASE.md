# Phase 1: Source Inventory

## Objective

Register and classify the source materials, map workbook roles, document quality limitations, and prepare a verified handoff to the next phase without altering original files.

## Scope

This phase covers six XLSX files and three scanned PDF documents in the project source folder.

## Deliverables

- Source metadata catalog.
- PDF and workbook role maps.
- Data-quality and extraction limitations.
- Explicit acceptance and handoff records.

## Constraints

Original source files are immutable. No academic rule, threshold, percentage, or course mapping is invented in this phase.
