# Handoff

## Đóng phase khi

- [x] Có extraction run bất biến, field evidence và trạng thái review.
- [x] PDF text-layer adapter chạy qua service/API.
- [ ] File scan/image có adapter OCR riêng.
- [ ] Confidence thấp tạo human-review item.
- [x] Có test raw field extraction và review fallback.

## Không thuộc phase

- Suy luận miễn môn.
- Tự động phê duyệt hồ sơ.
- Fine-tune model trên dữ liệu học sinh.
