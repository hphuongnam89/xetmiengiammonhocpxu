# Risks

- Thiết kế entity không thay thế việc xác nhận rule học thuật ở Phase 2.
- Import sai mapping có thể làm sai recommendation; phải giữ raw evidence và trạng thái review.
- Lưu file nhạy cảm không mã hoá hoặc phân quyền sai có thể gây lộ dữ liệu cá nhân.
- Cost/token chỉ đáng tin khi ghi nhận từ response provider, không ước lượng ở giao diện.
- Mô hình thay đổi mà không version sẽ làm mất khả năng tái lập kết quả.
